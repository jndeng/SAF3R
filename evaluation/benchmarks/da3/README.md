# DA3-Bench

`./bench` contains evaluation code copied or modified from [DA3-Bench](https://github.com/ByteDance-Seed/Depth-Anything-3/tree/main/src/depth_anything_3/bench).

Some DA3 evaluation-related utilities, such as `pose_align.py` and `geometry.py`, are also included here to avoid depending on the DA3 core codebase.

`da3bench_utils.py` was written for my own evaluation pipeline.
